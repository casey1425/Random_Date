# 랜덤 데이트 뽑기

지하철 노선과 서울 안의 역을 뽑고, 점심·컨텐츠·저녁까지 한 번에 정하는 커플용 웹페이지입니다.

- 빌드 없이 `index.html` 하나로 동작합니다. 브라우저에서 바로 열면 됩니다.
- 노선 13개(1~9호선, 경의중앙·수인분당·신분당·공항철도)와 서울 안의 역 중에서 뽑습니다. 노선을 바꾸면 역도 새로 뽑고, 역만 따로 바꿀 수도 있습니다.
- 점심과 저녁은 음식 종류가 겹치지 않게 뽑습니다. 1인 기준 1만원 안팎 / 2만원대까지 중에서 고를 수 있고, 비싼 메뉴는 넣지 않았습니다.
- 데이트 컨텐츠 40개(실내 24, 야외 16)에서 뽑거나 직접 고를 수 있습니다. 실내/야외만 뽑는 필터도 있습니다.
- 모든 칸은 "바꾸기"로 그 칸만 다시 뽑을 수 있습니다.
- 확정한 코스는 날짜와 함께 기록되고, 다녀온 뒤 체크할 수 있습니다. 기록은 브라우저 `localStorage`에만 저장됩니다.

## 사이트로 열기

GitHub Pages: Settings → Pages → Branch `main` / `/ (root)`.

## 데이터 수정

`index.html` 안의 `LINES`(노선·역), `MEALS`(메뉴, `p`가 가격대), `ACTS`(컨텐츠, `t`가 실내/야외)를 고치면 됩니다.
