# 랜덤 데이트 뽑기

먹을 것, 갈 곳, 할 것을 슬롯머신처럼 한 번에 뽑는 커플용 웹페이지입니다.

- 빌드 없이 `index.html` 하나로 동작합니다. 브라우저에서 바로 열면 됩니다.
- 마음에 드는 칸은 고정하고 나머지만 다시 뽑을 수 있습니다.
- 뽑기판 항목을 직접 추가하고 삭제할 수 있습니다.
- 확정한 데이트는 날짜와 함께 기록되고, 다녀온 뒤 체크할 수 있습니다.
- 뽑기판과 기록은 브라우저 `localStorage`에만 저장됩니다. 기기마다 따로 관리됩니다.

## 사이트로 열기

GitHub Pages: Settings → Pages → Branch `main` / `/ (root)`.
